# 32-bit RISC Processor Design and Verification

## 📌 Overview
This repository contains the design, implementation, and verification of a 32-bit RISC processor as part of the Capstone Project.

## 🎯 Objectives
- Implement a 32-bit RISC processor in Verilog.
- Verify functionality using testbenches and simulations.
- Document the design flow and results.

## 🗂️ Project Structure
- 01_Specification/ – Architecture overview, ISA, datapath, control signals
- 02_RTL_Design/ – Verilog modules (ALU, Register File, Control Unit, Datapath, Processor)
- 03_Testbenches/ – Testbenches for verification
- 04_Verification/ – Simulation results and waveforms
- 05_Documentation/ – Reports and documentation

## 🛠️ Tools Used
- Verilog HDL
- ModelSim / Quartus
- GitHub for version control
